# 素材アップロード用フォルダ

ここに元データを置いてください。ファイル名は下記に合わせていただけると、そのまま差し替えできます。
**判断に迷う場合はファイル名そのままでOKです。**こちらで振り分けます。

## アップロード方法（GitHub の画面から）

1. このフォルダのページを開く
   → https://github.com/tagukichi/eight-fields.renewal/tree/claude/eight-fields-redesign-9c64yk/assets-original
2. 右上の **Add file → Upload files**
3. ファイルをドラッグ＆ドロップ
4. 下の **Commit changes** を押す（ブランチはそのままで大丈夫です）

アップが終わったらチャットで教えてください。差し替えて反映します。

## ファイル形式について

- **写真** … JPG / PNG / HEIC どれでも大丈夫です。こちらで最適化します
- **ロゴ** … SVG / AI / EPS / PDF があれば一番きれいです。デザイン会社さんから受け取ったデータがあればそのままで
- **サイズ** … 大きい分には問題ありません。圧縮はこちらで行います
- 1ファイル 25MB まで（GitHub の画面からアップする場合の上限です）
