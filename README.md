## 1. デザインの方向性

現行ロゴ（∞マーク）から抽出した **ブランドブルー `#43ACDC`** と **ブランドイエロー `#FFBC2C`** を軸に、
信頼感を出すためのディープネイビー `#0B2E42` を加えた3色構成です。

| 役割 | 色 | 用途 |
|---|---|---|
| Logo Blue | `#43ACDC` | 図版・アイコン・ハイライト |
| Blue (AA) | `#1C7FA8` | リンク・本文中のアクセント（コントラスト確保用） |
| Logo Amber | `#FFBC2C` | 主要CTA・アクセントライン |
| Deep Navy | `#0B2E42` | ヒーロー／フッターの地色 |

設計の考え方:

- **「営業会社＝施工会社」という強みを前面に。** 現行サイトでは会社概要の一項目だった内容を、
  トップページの「選ばれる3つの理由」として引き上げています。
- **6サービスを横断して見せる。** 単体販売ではなく「組み合わせるほど効果が出る」構成にし、
  サービス一覧に「つくる → ためる → 使う → 保つ」の導線を追加しました。
- **問い合わせまでの距離を短く。** 追従CTAバー（SP）、全ページ共通のコンタクトバンド、
  ヘッダーの電話番号を常設しています。
- **アクセシビリティ。** キーボード操作・スキップリンク・`prefers-reduced-motion` に対応。
  文字色は本文で 4.5:1 以上のコントラストを確保しています。

## 2-a. プレビューの閲覧制限について ⚠️

デザイン案プレビューには ID / パスワード（ともに `eight`）の入力画面を設けています。

**ただし、これは Basic 認証ではありません。** GitHub Pages は静的ファイルを配信するだけの
サービスで、`.htaccess` などのサーバー側設定を持てないため、**本来の Basic 認証は技術的に
設置できません**。現在の実装は JavaScript による簡易的な閲覧ゲートで、次の効果があります。

- URL を知っただけの第三者が、そのまま中身を見ることを防ぐ
- `noindex` と `robots.txt` により検索エンジンに載らないようにする

一方で、**ブラウザの開発者ツールを使える人は回避できます**（HTML/CSS/画像は直接取得可能）。
本当に見られては困る内容を置く段階になったら、次のいずれかへの切り替えをご検討ください。

| 方法 | Basic認証 | 備考 |
|---|---|---|
| Netlify / Cloudflare Pages に配信先を変更 | ○ | 設定ファイル1つで本物のBasic認証。無料枠あり |
| Vercel | ○ | Deployment Protection（要 Pro） |
| GitHub Pages のまま（現状） | × | 上記の簡易ゲートのみ |
| お客様のサーバーに設置 | ○ | `.htaccess` で設定 |

配信先の変更をご希望でしたらお知らせください。ビルド成果物は同じ `docs/` なので、移行は容易です。

## 2-b. GitHub Pages の初回設定（1回だけ必要）

デプロイ用の GitHub Actions ワークフローは設定済みですが、**Pages の初回有効化だけは
リポジトリ設定から行う必要があります**（GitHub の仕様上、ワークフローの `GITHUB_TOKEN` では
Pages サイトを新規作成できないため）。

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** に変更
3. **Actions → Deploy design proposal to GitHub Pages → Run workflow** で再実行

以降は `claude/eight-fields-redesign-9c64yk` への push で自動デプロイされます。

> リポジトリが Private の場合、GitHub Pages の公開には有料プラン（Pro / Team 以上）が必要です。

├── dist/eight-fields.zip    ★ WordPress にアップロードするテーマ

### アニメーションについて

スクロール演出とトップページのファーストビューは [GSAP 3.15](https://gsap.com/) + ScrollTrigger で
実装しています。CDN ではなくテーマに同梱しているため、外部サービスへの依存はありません
（`assets/js/vendor/`）。GSAP は Standard "no charge" ライセンスで、コーポレートサイトでの利用は無償です。

GSAP が読み込めない場合は IntersectionObserver によるシンプルなフェードインに、
JavaScript が無効な場合は `<noscript>` で全要素を表示状態にフォールバックします。
`prefers-reduced-motion: reduce` の環境ではアニメーションを行いません。

## 4. WordPress テーマの導入

配布用のテーマは `dist/eight-fields.zip` です。GitHub 上でそのままダウンロードできます。

### インストール

1. WordPress 管理画面 →「外観 → テーマ → 新規追加 → テーマのアップロード」
2. `eight-fields.zip` を選択してインストール → 有効化

リポジトリから直接置く場合は `theme/eight-fields` を `wp-content/themes/` にコピーしてください。

### 初期セットアップ（1回だけ）

有効化したら「**外観 → 初期セットアップ**」を開いてください。
押す前に、どのページを新しく作り、どのページがすでにあるかの一覧が表示されます。

- 固定ページ 5 件（ホーム／会社概要／ごあいさつ／お知らせ／お問い合わせ）
- サービス（CPT `service`）6 件 — キャッチコピー・メリット・よくあるご質問つき
- アイキャッチ画像 — テーマ同梱の写真をメディアライブラリへ取り込み
- メニュー「メインメニュー」— ヘッダーとハンバーガーに割り当て（サービスの下に6件をぶら下げ）
- 表示設定 — ホームをトップページ、お知らせを投稿ページに

**既存サイトのテーマを入れ替えた場合は、チェックボックスを外したまま実行してください。**
初期状態では既存の内容に手を加えません。

| | 既定（安全） | 「上書きする」にチェック |
|---|---|---|
| 同じスラッグのページ | タイトル・本文・抜粋・並び順・公開状態をそのまま維持し、空欄だけ埋める | デザイン案の内容で置き換える |
| トップページ／投稿ページの設定 | すでに設定済みなら変更しない | ホーム／お知らせに設定し直す |
| メニュー | 既存の「メインメニュー」の並び順を維持 | 同左 |
| アイキャッチ画像 | 未設定のものにだけ入れる | 同左 |
| 既存の投稿・カテゴリー・メディア | 触らない | 触らない |

上書きは、新しく立てたサイトを一気に整えたいとき用です。
どちらのモードでも、同じページが増えることはありません（スラッグで照合します）。

そのあと、次の2つだけ手で設定してください。

1. **設定 → パーマリンク** — 「投稿名」を選んで保存（サービスの個別ページのURLが有効になります）。
2. **お問い合わせフォーム** — 下記「フォームの設置」を参照。

お知らせ（投稿）はセットアップの対象外です。デザイン案に載せている8件はサンプルなので、
実際の記事を投稿してください。1件もないあいだ、トップページのお知らせ欄は空欄になります。

### フォームの設置

プラグイン Contact Form 7 を入れ、`theme/eight-fields/docs/contact-form-7.txt`
（テーマフォルダ内の `docs/contact-form-7.txt`）の内容を貼り付けてください。
デザイン案とまったく同じ見た目のフォームになります。テーマ側に Contact Form 7 用の
スタイルを入れてあるので、フィールドごとにクラスを付ける作業は不要です。

フォームを置くまでのあいだ、お問い合わせページにはフォームの代わりに電話のご案内が出ます
（動かないフォームを置いたままにしないための動作です）。

### CPT `service` について

`service` が未登録の環境でもテーマ単体で動くよう、`inc/post-types.php` で登録しています。
CPT UI などで既に登録済みの場合は `post_type_exists()` により自動的にスキップされるため、
既存の設定を上書きしません。アーカイブは現行サイトに合わせて `/service_/`、
個別ページは `/service/<slug>/` です。
