Message

全てのご縁を大切に、
日々精進して参ります。

私たちエイトフィールズは、お客様の叶えたい願望、お客様のニーズに沿った提案で 喜んでいただきたいと思っております。

そして何よりご縁を大事にが我が社のスローガンとしてあります。 お客様、社員のみんな、全ては人と人との繋がり・ご縁で出会えたものになります。 全てのご縁を大切に、日々精進して参ります。

Our stance

私たちが大切にしていること

VALUE 01

誠実と誇り

できることとできないことを、はっきりお伝えします。 売るための説明ではなく、判断していただくための説明を。

VALUE 02

一人一人の出会いに感謝

工事が終わってからが、お付き合いの始まり。 設備以外のお困りごとも、気軽に声をかけていただける関係を目指しています。

VALUE 03

環境活動の推奨

エネルギーを自分でつくり、ためて、使う暮らしへ。 地域・日本の信頼に生きる活動として、無理のない一歩をご提案します。
